# 창백한 청수리

디스코 엘리시움의 **창백(The Pale)**이 북한 압록강 국경 마을에 나타난다는 설정의 텍스트 CRPG이자 TRPG입니다.

- **CRPG**: `index.html`을 브라우저로 열면 바로 플레이할 수 있습니다. 빌드나 서버가 필요 없습니다.
- **Godot 버전**: [`godot/`](godot/README.md) 폴더를 Godot 4.3 이상에서 열고 F5를 누르면 됩니다. 데스크톱과 모바일용으로 빌드할 수 있습니다.
- **TRPG**: [`RULES.md`](RULES.md)에 테이블에서 쓰는 규칙과 GM용 시나리오가 있습니다.
- **스토리 바이블**: [`STORY.md`](STORY.md)에 설정, 인물, 날짜별 전개, 분기, 플래그를 정리해 두었습니다.
- **아트 바이블**: [`ART.md`](ART.md)에 화풍과 그림 목록, 프롬프트가 있습니다.

## 특징
- 기술 12개가 내면의 목소리로 말을 겁니다(주체논리, 내면의 백두, 장마당 본능 등).
- 2d6 판정: 흰 판정은 기술이 오르면 다시 시도할 수 있고, 붉은 판정은 한 번뿐입니다.
- 사상함: 생각을 내면화하면 기술 보정을 받고 새 선택지가 열립니다.
- 7일 구성입니다(현재 6일째까지 작성). 3일째 밤의 보고서가 중간 분기점이고, 그동안의 행보에 따라 4일째에 창백이 물러나거나 넓어집니다.
- 기억한 이름: 창백에 맞서는 자원입니다. 구호는 하얘지고, 불린 이름은 남습니다.
- 체력과 사기, 창백 노출도, 저장과 불러오기를 지원합니다.
- 바깥세상과 닿는 소지품이 있습니다: 단파 라디오, 노텔과 남조선 드라마 알판, 중국 손전화.
- 5일째부터 여섯 세력이 등장하고, 세력 호감도에 따라 음식과 장비를 받습니다. 음식은 인물 화면에서 먹어 회복합니다.
- 그림은 `python3 tools/gen_art.py --missing`으로 `ART.md`의 목록을 Gemini에서 바로 생성할 수 있습니다(`GEMINI_API_KEY` 필요).
- 결말은 7일째에 정할 예정이라 아직 확정하지 않았습니다. 지금은 사망 결말 2개만 연결돼 있습니다.

## 시나리오 확장하기
`index.html` 안의 `STORY` 객체에 노드를 추가하면 됩니다.

```js
my_node: {scene:'장소명', on:{flag:'x', sp:1}, text:[
  '서술 문장',
  '@logic: 기술의 목소리',
  '#인물이름: 대사',
], passives:[{s:'eye', dc:10, t:'수동 판정 성공 시 대사'}],
options:[
  {t:'일반 선택지', go:'other_node'},
  {t:'판정 선택지', check:{s:'rhet', dc:12, red:true}, ok:'win', no:'lose', req:['x'], not:['y']},
]},
```

시나리오를 고친 뒤에는 `npm install && npm run export`를 실행해 Godot용 JSON(`godot/data/`)을 다시 만드세요.
