# 창백한 청수리

디스코 엘리시움의 **창백(The Pale)**이 북한 압록강 국경 마을에 나타난다는 설정의 텍스트 CRPG이자 TRPG입니다.

- **CRPG**: `index.html`을 브라우저로 열면 바로 플레이할 수 있습니다. 빌드나 서버가 필요 없습니다.
- **TRPG**: [`RULES.md`](RULES.md)에 테이블에서 쓰는 규칙과 GM용 시나리오가 있습니다.

## 특징
- 기술 12개가 내면의 목소리로 말을 겁니다(주체논리, 내면의 백두, 장마당 본능 등).
- 2d6 판정: 흰 판정은 기술이 오르면 다시 시도할 수 있고, 붉은 판정은 한 번뿐입니다.
- 사상함: 생각을 내면화하면 기술 보정을 받고 새 선택지가 열립니다.
- 체력과 사기, 창백 노출도, 저장과 불러오기를 지원합니다.
- 결말 4개(비밀 결말 1개 포함)와 사망 결말 2개가 있습니다.

## 시나리오 확장하기
`index.html` 안의 `STORY` 객체에 노드를 추가하면 됩니다.

```js
my_node: {scene:'장소명', on:{flag:'x', sp:1}, text:[
  '서술 문장',
  '@logic: 기술의 목소리',
  '#인물이름: 대사',
], passives:[{s:'eye', dc:10, t:'수동 판정 성공 시 대사'}],
options:[
  {t:'일반 선택지', go:'other_node'},
  {t:'판정 선택지', check:{s:'rhet', dc:12, red:true}, ok:'win', no:'lose', req:['x'], not:['y']},
]},
```
